# Git Typing Trainer

Git の commit / branch / push などをタイピング形式で練習できるウェブアプリケーションです。  
ゲーム感覚で Git コマンドを繰り返し入力しながら習得できます。

## 使い方

1. リポジトリをクローンまたは ZIP を展開します。

    ```bash
    git clone https://github.com/your-username/git-typing-trainer.git
    ```

2. `git_typing/index.html` をブラウザで開いて開始します。

3. 必要に応じて SCSS を CSS にコンパイルしてください。

    ```bash
    sass css/style.scss css/style.css
    ```

## 開発環境

- HTML5 / SCSS / JavaScript
- Sass コンパイラ推奨
